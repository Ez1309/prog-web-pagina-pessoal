# Portfólio Pessoal - Programação Web (GAC116 - UFLA)

Página pessoal (portfólio web) desenvolvida como atividade prática 02 para a disciplina GAC116 - Programação Web da Universidade Federal de Lavras (UFLA). O projeto implementa o mesmo design e conteúdo utilizando dois frameworks CSS distintos para fins de comparação prática.

## 📋 Descrição do Projeto
O objetivo deste projeto é construir uma página web responsiva e moderna para apresentar trajetória profissional, habilidades, projetos em destaque e informações de contato. Para analisar as diferenças de sintaxe, arquitetura e uso de classes utilitárias, o portfólio foi desenvolvido em duas versões independentes:
* **Versão 1:** Utilizando o framework **Bootstrap 5.3**.
* **Versão 2:** Utilizando o framework **Bulma CSS**.

A página principal atua como uma "Landing Page" que permite ao visitante escolher qual versão do framework deseja acessar.

## 🛠️ Tecnologias Utilizadas
* **HTML**: Estruturação semântica do conteúdo da página.
* **CSS**: Criação de classes utilitárias, sobrescrita de variáveis padrão dos frameworks e controle avançado da paleta de cores.
* **JavaScript**: Lógica para alternância de temas (Dark/Light mode) e controle do menu responsivo (Bulma).
* **Bootstrap 5**: Framework CSS baseado em utilitários e componentes nativos.
* **Bulma CSS**: Framework CSS moderno baseado inteiramente em Flexbox.
* **FontAwesome**: Biblioteca para os ícones vetoriais.

## ✨ Funcionalidades e Destaques
1. **Design Equivalente:** Ambas as versões (Bootstrap e Bulma) possuem o mesmo layout, demonstrando a versatilidade de alcançar o mesmo resultado com ferramentas diferentes.
2. **Tema Claro / Escuro (Dark Mode):** Sistema de troca de temas dinâmico via JavaScript, com variáveis CSS adaptando cores e contrastes perfeitamente para não causar fadiga visual.
3. **Responsividade Integrada:** Layout adaptável para smartphones, tablets e desktops (Mobile First).
4. **Paleta Customizada:** Sobrescrita das variáveis primárias e secundárias dos frameworks para fugir das cores padrão e criar uma identidade visual única (Tons de Verde Escuro e Lilás).
5. **Componentes Customizados:** Fotos com recorte dinâmico circular em CSS, cards com efeitos flutuantes (`hover`) e navegação fixa com ancoragem suave (`smooth scroll`).
